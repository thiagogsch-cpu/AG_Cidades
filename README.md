# ✈️ European Travel Decision & Optimization Platform

Uma plataforma analítica SaaS desenvolvida em Python e Streamlit para apoio à decisão multicritério (MCDA) no planeamento de viagens pela Europa.

## 🚀 Funcionalidades
- **Ranking Dinâmico Ponderado:** Algoritmo com normalização Min-Max para 18 indicadores multidimensionais (Euromonitor, UNESCO, Numbeo, TripAdvisor).
- **Otimização de Roteiros (AG):** Algoritmo Genético integrado para geração de itinerários otimizados sob restrições de tempo e orçamento.
- **Auditabilidade & Explicabilidade:** Decomposição transparente dos scores e custos por destino.
- **Interface SaaS Moderna:** UI/UX com navegação em cards e tabelas interativas.
- **Pipeline ETL Automático:** Módulo para atualização contínua de indicadores e persistência de preferências em JSON.
